# Play mode pull request 3: the HUD reader. Implementation plan

> For agentic workers: REQUIRED SUB-SKILL: use superpowers:subagent-driven-development to implement
> this plan task by task. Steps use checkbox syntax. Like the pull request 2 plan, this plan fixes
> interfaces, constants, behaviour and test cases, and leaves the function bodies to the implementer.
> Where a body or a constant is given, use it verbatim. The constants are calibration values measured
> in a spike on real footage; when a synthetic test image does not trigger them, change the test
> image, never the constant.

Goal: read the touch controls of mobile Brawl Stars Showdown footage: a per-frame "mobile HUD
visible" verdict that the YouTube ingest uses to drop frames without a HUD, and a per-source
`actions.jsonl` with the move vector, the aim offset and the button states, with channels that
cannot be read honestly rejected per source and counted in the report.

Architecture: `tools/play/hud.py` is the detector: Hough circles on the gray image inside a search
box and a radius band expressed relative to the content box, then a class verdict from the median
HSV inside the circle. `tools/play/actions.py` runs per source over frames already in the dataset:
it learns the attack home and the joystick base radius from the whole source, runs the clean HUD
check per channel, then writes one action row per frame. The border measurement in
`tools/play/dataset.py` changes its rule so an overlay that reaches the frame edge cannot hide a
pillarbox, and both the ingest trim and the HUD reader use that one function.

Tech stack: Python 3.13, uv, pytest, ruff, OpenCV and numpy (already dependencies). Nothing new.

Spec: `docs/superpowers/specs/2026-09-18-play-mode.md`, section 10 (HUD reader) and section 8 (the
HUD filter moved here). This plan implements build order step 3. The cloned policy that will read
`actions.jsonl` is release 1.3.0 and its own proposal; nothing here trains anything.

## Measured facts (HUD spike, 2026-09-20, two YouTube sources plus 138 emulator menu frames)

- Colour masks first, circles second, fails: a pink arena floor turns the attack mask into one
  blob (attack found in 2 of 13). Circles first, colour second, works.
- HUD visible rule `super and (attack or knob)`: recall 28 of 30, precision 28 of 28, 0 of 138
  emulator menu frames. Super alone: 30 of 30 and 0 of 138. Attack alone fires on 44 percent of
  menu frames and the knob on 38 percent, so neither may stand alone.
- The two sources agree on button anchors to 0.023 in u and 0.016 in v with no tuning between
  them. Pinned buttons move 2 px median frame to frame.
- 13.1 ms per frame, JPEG decode included.
- The joystick floats: there is no rest position, so the base is found per frame. A free-radius
  search finds a base in 0.876 of knob frames but its radius spreads 0.094 to 0.193 of the
  content height around a median of 0.149, and one of three checked move vectors was wrong in y.
  The fix this plan builds: learn the base radius once per source, then search for the centre
  only, at that radius.
- A plain attack tap is not observable at 2 frames per second. Only aiming is: the attack disc is
  dragged away from its home. Displacement from home is bimodal (p50 3 px, p95 0.198 of the
  content height).
- A border measured as "the mean gray of the column is above the border level" is fooled by a
  creator overlay that reaches the frame edge (the box came out full width, shifting every relative
  coordinate by 11 percent). "More than half of the column's pixels are above the border level"
  is not fooled.

### Task 2: `tools/play/hud.py`, the detector and the visible rule

Files: create `tools/play/hud.py`, `tests/hud_draw.py`, `tests/test_play_hud.py`.

Coordinates: a box is `(x, y, w, h)` in frame pixels, as `dataset.content_box` returns. For a
point, `u = (px - x) / w`, `v = (py - y) / h`. Radii are fractions of `h`.

Constants, verbatim:

```python
SEARCH = {  # class: (u0, v0, u1, v1, r_min, r_max), radii as shares of the box height
    "attack": (0.80, 0.44, 1.00, 0.78, 0.042, 0.095),
    "super": (0.73, 0.69, 0.81, 0.78, 0.040, 0.090),
    "gadget": (0.82, 0.85, 0.90, 0.93, 0.038, 0.085),
    "hyper": (0.64, 0.85, 0.72, 0.93, 0.038, 0.085),
    "knob": (0.00, 0.55, 0.30, 1.00, 0.040, 0.095),
}
BLUR = 5
HOUGH_DP = 1.2
HOUGH_MIN_DIST = 0.05  # share of the box height
HOUGH_EDGE = 110  # param1
HOUGH_VOTES = 38  # param2
INNER = 0.62  # the colour is read inside this share of the radius
BASE_FREE = (1.3, 2.6, 26)  # knob radii from, to, and param2, when the base radius is unknown
BASE_FIXED = (0.95, 1.05, 22)  # shares of the known radius, and param2
```

Colour states, OpenCV HSV with H in 0..179, tested on the median S and V and the circular mean
of H over the inner disc. The first matching state in the listed order wins; no match means the
circle is not that class.

| class  | state    | test                                                         |
| ------ | -------- | ------------------------------------------------------------ |
| attack | `red`    | `(h >= 166 or h <= 17) and s >= 120 and v >= 100`            |
| attack | `dim`    | `(h >= 166 or h <= 17) and 15 <= s < 120 and 90 <= v <= 180` |
| super  | `blue`   | `96 <= h <= 120 and s >= 110 and v >= 90`                    |
| super  | `gold`   | `4 <= h <= 32 and v >= 225`                                  |
| super  | `white`  | `s <= 70 and v >= 235`                                       |
| super  | `dark`   | `s <= 70 and 60 <= v <= 115`                                 |
| gadget | `green`  | `40 <= h <= 90 and s >= 140 and v >= 110`                    |
| gadget | `grey`   | `s <= 40 and 80 <= v <= 175`                                 |
| hyper  | `purple` | `120 <= h <= 150 and s >= 90 and v >= 80`                    |
| knob   | `blue`   | `96 <= h <= 120 and s >= 170 and v >= 130`                   |

The state names are colours on purpose: what a gold super means is the policy's business, not the
reader's.

Interfaces produced:

```python
@dataclass(frozen=True)
class Found:
    cls: str
    x: float  # frame pixels
    y: float
    r: float
    state: str

def frame_box(pad: tuple[int, int, int, int]) -> tuple[int, int, int, int]
def inner_hsv(frame: np.ndarray, x: float, y: float, r: float) -> tuple[float, float, float]
def state_of(cls: str, h: float, s: float, v: float) -> str | None
def find(frame: np.ndarray, box: tuple[int, int, int, int]) -> dict[str, Found]
def visible(found: Mapping[str, Found]) -> bool
def base(frame, box, knob: Found, radius: float | None = None) -> Found | None
```

- `frame_box(pad)`: the content box of a fitted frame, `(left, top, FRAME_W - left - right,
FRAME_H - top - bottom)`.
- `inner_hsv`: circular mean of H (so 2 and 178 average to 0, not 90), medians of S and V, over
  the pixels within `INNER * r` of the centre, clipped to the frame.
- `find`: per class, crop the search box (clipped to the frame; a box narrower or lower than
  `2 * r_min` pixels yields nothing), gray, `cv2.medianBlur(BLUR)`, `cv2.HoughCircles` with the
  constants above and the class radius band, then walk the circles in the order OpenCV returns
  them and keep the first whose `state_of` is not None. A class that finds nothing is absent
  from the dict. Returned coordinates are frame pixels.
- `visible`: `"super" in found and ("attack" in found or "knob" in found)`.
- `base`: the joystick base ring around a knob. With `radius=None`, Hough inside a window of
  `BASE_FREE[1]` knob radii around the knob, radius band `BASE_FREE[0]..BASE_FREE[1]` knob radii,
  param2 `BASE_FREE[2]`. With a radius, band `BASE_FIXED[0]..BASE_FIXED[1]` of it, param2
  `BASE_FIXED[2]`, window of one radius around the knob. Either way, keep the first circle whose
  centre lies within its own radius of the knob centre (the knob is always inside its base);
  none gives None. `cls="base"`, `state="ring"`.

### Task 4: `tools/play/actions.py`

Files: create `tools/play/actions.py`, `tests/test_play_actions.py`.

Constants, verbatim:

```python
LEARN_SAMPLE = 200  # frames read to learn a source, spread evenly over it
MIN_HUD_FRAMES = 100  # fewer HUD frames than this and nothing about the source is trusted
HOME_BIN = 6  # px, the attack home is the fullest bin of this size
HOME_SHARE = 0.30  # the fullest bin must hold this share of the attack discs
ATTACK_RATE = 0.60  # attack discs per HUD frame, below this the aim channel is rejected
KNOB_RATE = 0.80  # knobs per HUD frame, below this the move channel is rejected
BASE_RATE = 0.70  # bases per knob frame, likewise
AIM_RADIUS = 0.198  # share of the box height; the p95 drag distance measured in the spike
AIMING_MIN = 0.2  # share of AIM_RADIUS past which the disc counts as dragged
```

Interfaces produced:

```python
@dataclass(frozen=True)
class Clip:
    box: tuple[int, int, int, int]
    hud_frames: int
    home: tuple[float, float] | None  # attack home, frame pixels
    base_radius: float | None  # frame pixels
    channels: dict[str, str]  # "move" and "aim": "ok" or the reason it was rejected

def spread(items: Sequence, n: int) -> list  # n items evenly over the sequence, all if fewer
def learn(frames: Sequence[np.ndarray], box, *, min_frames: int = MIN_HUD_FRAMES) -> Clip
def read(frame: np.ndarray, clip: Clip) -> dict
def run(root: Path, source: str, *, min_frames: int = MIN_HUD_FRAMES) -> dict
def main(argv: list[str] | None = None) -> int
```

- `learn`: run `hud.find` on every frame given; HUD frames are the `hud.visible` ones. Fewer
  than `min_frames` of them: both channels rejected with `too few HUD frames (<n>)`, `home` and
  `base_radius` None. Otherwise:
  - aim: attack rate below `ATTACK_RATE` rejects with `attack disc in <rate> of HUD frames`.
    Bin the attack centres at `HOME_BIN`; the fullest bin's mean is `home`; a fullest bin under
    `HOME_SHARE` of the discs rejects with `no stable attack home`.
  - move: knob rate below `KNOB_RATE` rejects with `joystick knob in <rate> of HUD frames`
    (this is the covered-joystick case). For each knob run `hud.base(frame, box, knob)` free;
    base rate below `BASE_RATE` of the knob frames rejects with `joystick base in <rate> of knob
frames`; else `base_radius` is the median free radius.
    Rates print with two decimals.
- `read`: one row of actions for one frame. Keys: `hud` (bool), `move` (`[x, y]` or None), `aim`
  (`[x, y]` or None), `aiming` (bool or None), `super`, `gadget`, `hyper` (state or None).
  `hud` False makes everything else None. `aim` needs the aim channel ok and an attack disc:
  `(disc - home) / (AIM_RADIUS * box height)`, each axis clipped to -1..1, rounded to 3;
  `aiming` is the vector length `>= AIMING_MIN`. `move` needs the move channel ok, a knob, and
  `hud.base(frame, box, knob, clip.base_radius)`: `(knob - base) / base_radius`, clipped and
  rounded the same way. y grows downward, as in the image. There is no "attack pressed" key: a
  tap is not observable in stills, and the docstring says so.
- `run`: `dataset.check_source`; the source's rows from `dataset.index_rows(root)` in file
  order; no rows raises `ValueError("<source> is not in the index")`; `box` is
  `dataset.content_box` over `spread(frames, 24)`; `learn` over `spread(frames, LEARN_SAMPLE)`;
  then `read` every frame. Frames are decoded one at a time, never all held in memory: `learn`
  and `content_box` get their samples read for them, the full pass streams. Writes
  `frames/<source>/actions.jsonl` (one row per index row: `file`, `t`, then the `read` keys; the
  file is written to a `.tmp` beside it and renamed, so an interrupted run never leaves half a
  file) and `frames/<source>/actions.meta.json` (`box`, `hud_frames`, `home`, `base_radius`,
  `channels`, the constants above by name, and the counts). Returns the counts: `frames`, `hud`,
  `move`, `aim`, `aiming`.
- `main`: `--source` (repeatable, default every source of kind `youtube` in the index),
  `--root`. Per source one line: `<source>: <frames> frames, HUD on <hud>, move on <move>, aim on
<aim> (aiming <aiming>)`, then one line per rejected channel: `<source>: <channel> rejected,
<reason>`. Last line: `<n> sources: <m> with every channel, <k> with a rejected channel`.
  Returns 2 on a bad source name or a source not in the index, else 0.
